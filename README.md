# E-RIDE E-bike Shop

Responsive e-bike shop front-end built with HTML, CSS and vanilla JavaScript.

## Run it
Open `index.html` in a browser, or use VS Code Live Server.

## Included
- Responsive homepage and category cards
- Search, category filtering and price sorting
- Product cards with demo product data
- Favorites (in-memory for this demo)
- Interactive cart drawer with quantity controls and subtotal
- Newsletter demo form
- Mobile navigation

## Notes
This is a front-end demo. Cart and favorites reset when the page reloads. Checkout, user accounts, newsletter subscription, inventory and orders need a backend/payment integration. Product photos are loaded from Unsplash and therefore need an internet connection.
